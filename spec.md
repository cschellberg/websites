This a project for the development of static html sites.
Each subdirectory will be a different site
All files for that particular site will be contained in that subdirectory.
Images will be stored in this directory and referenced in the html files.
CSS files will also be stored in this directory and linked in the html files.
All sites will be independent and self-contained, with no shared assets or dependencies between them.
All sites will be in spanish and will be designed to be responsive and mobile-friendly.
